/* Hinweise zum Aufbau der 7 stelligen Makro Definitionen für Telegramme.   */
/* Angaben beziehen sich auf die TLS Dokumentation.                         */
/*                                                                          */
/* 1. Stelle - Funktionscodes                                               */
/* --------------------------                                               */
/*   DE_ABRUF  ... 1                                                        */
/*   SM_ABRUF  ... 2                                                        */
/*   DE_SENDEN ... 3                                                        */
/*   SM_SENDEN ... 4                                                        */
/*                                                                          */
/* 2 - 4. Stelle - TLS Id                                                   */
/* ----------------------                                                   */
/*   DE_ABRUF  ... ID in Abrufrichtung (R)                                  */
/*   SM_ABRUF  ... ID in Abrufrichtung (R)                                  */
/*   DE_SENDEN ... ID in Antwortrichtung (A) - R/A Definition mit selber ID */
/*   SM_SENDEN ... ID in Antwortrichtung (A) - R/A Definition mit selber ID */
/*                                                                          */
/* 5 - 7. Stelle - Typ                                                      */
/* -------------------                                                      */
/*   Entsprechender Typ laut TLS Dokumentation                              */
/*                                                                          */
/* ======================================================================== */
