# c2vba-data

Einige Protobuf-Strukturen zur Ergebnis-Publikation über Kafka

* CommStates:         Kommunikationsstatus von Anlagen, kann auch beim sdbby-service angefragt werden
* StrategyStates:     Status/Aktivität von Strategien, kann auch beim sdbby-service angefragt werden
* DatexIIContent:     DATEX-II-Inhalte
