// Hinweise:
//
// BYTE, SHORT, LONG sind Getter für Ganzzahlen. BYTE iste ohne Vorzeichen. SHORT und LONG
// sind mit Vorzeichen und little endian. Um dies zu ändern, müssen die Zusätze 'signed', 
// 'unsigned' und/oder 'big endian' verwendet werden
//
// NODE ist ein Getter speziell für Knotennummern. Diese sind immer ohne Vorzeichen und 'little endian'. 
// 
// TIME verwendet einen Spezifikations-String, z.B. 'h m s'.
// Der String besteht aus Buchstaben, die durch Leerzeichen oder Doppelpunkte getrennt werden. 
// Folgende Buchstaben werden unterstützt
// d für Tag
// M für Monat
// c für Jahrhundert (ein Byte von 0-99)
// y für Jahr (ein Byte von 0-99)
// Y für Jahr (zwei Byte, 0-9999, litle endian)
// h für Stunde, bit 8 enthält die Flagge für die Sommerzeit
// m für Minute
// s für Sekunde
// z initialisiert Stunde/Minute/Sekunde mit null anstelle der aktuellen Uhrzeit, sollte als erstes verwendet werden
// Wenn ein Buchstabe nicht verwendet wird, wird der entsprechende Wert aus der aktuellen Uhrzeit übernommen
//
// BLOCK liest ein Byte array ein. Die Größe kann auf folgende Arten ermittelt werden:
// 'with size' erwartet die Größe im ersten byte
// 'to end' liest alle bytes bis zum Ende des DE-Blocks
//  'fixed size <n>' liest n bytes
//
// SKIP ignoriert exakt ein byte
//
// ARRAY [ ... ]
// Einlesen eines Array von gleichen Objekten
//
// IF (condition) { ... } ELSE { ... }
// Die condition prüft eine interne Variable auf einen vorgegebenen Wert.
// Wenn die Variable gespeichert werden soll, muss dies mit einem zusätzlichen SET erfolgen
// Das ELSE ist optional. 
//
// OPT { ... }
// Liest die angegebenen Daten ein, falls der DE-Block noch nicht abgearbeitet ist.
//
// Interne Variablen unterscheiden sich in automatische und benutzerdefinierte Variablen.
// Benutzerdefinierte Variablen beginnen mit dem '$' Zeichen.
// Automatische Variablen beginnen mit dem '#'-Zeichen. Es existieren folgende automatische Variablen:
// #Node Knotennummer
// #TlsFg Funktionsgruppe des Einzeltelegramms
// #TlsId Id des Einzeltelegramms
// #TlsJob Jobnummer
// #ActualTime Die aktuelle Uhrzeit
// #De DE-Nummer
// #DeLen Länge des DE-Blocks (inkl. DE-Nummer und DE-Typ)
//
// HEADER DE-Blöcke. DE-Blöcke, die als HEADER gekennzeichnet sind, speichern alle Inhalte automatisch 
// in einer speziellen internen Variablen. Daher ist hier kein '$'-Zeichen zu verwenden
//  
// SET attribute := expression
// Setzt den Wert eines Attributs mit dem Inhalt eines Ausdrucks.
// Der Ausdruck kann eine interne Variable, eine konstante Zahl oder eine Verknüpfung
// mit einem der Operatoren + - * / & >> << sein. Die Operatoren werden von links nach rechts
// ohne Priorisierung ausgewertet. Eine Klammerung ist möglich.
//
